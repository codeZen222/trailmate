⚠️ 下载后必须先改名，否则装不上
下载平台会把文件名改成随机字符（常见后缀是 .zip）。请按下面顺序处理：

1. 在手机「文件管理」里找到刚下载的文件
2. 长按 → 重命名
3. 把整个名字改成 TrailMate.apk（关键是末尾的 .apk）
4. 点开它，提示「未知来源」时选允许，即可安装

若系统提示「未加密/风险应用」，选择「继续安装 / 仍要安装」即可 —— 这是所有未上架应用的正常提示，不是病毒。

安装步骤

  1. 点上方按钮下载 TrailMate-v1.0.3.apk
  2. 打开文件，系统会提示「禁止安装未知来源应用」
